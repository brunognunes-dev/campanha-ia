## 3. Configuração desejada

O fluxo correto deverá ser:

Webhook Campanha
→ Validar Dados Essenciais
→ Google Sheets - Registrar Campanha
→ Gmail - Enviar para Revisão
→ Google Sheets - Confirmar Envio
→ Respond to Webhook - Sucesso 200

A saída False do nó de validação deverá continuar retornando erro HTTP 400.

### Google Sheets

Documento:

`MarketFlow AI - Campanhas DEV`

Aba:

`Campanhas`

Colunas:

- submission_id
- submitted_at
- product_service
- objective
- channels
- report_markdown
- validation_status
- delivery_status

O primeiro nó deve registrar a campanha com `delivery_status = pending`.

O segundo nó deve localizar o registro pelo `submission_id` e atualizar para `delivery_status = sent` após a confirmação do Gmail.

Use operações apropriadas do Google Sheets e confira os mapeamentos.

## 5. Tratamento de erros

Garanta que:

- Dados inválidos retornem HTTP 400.
- A resposta de sucesso só seja emitida depois da confirmação das operações obrigatórias.
- Falhas do Google Sheets não sejam apresentadas como sucesso.
- Falhas do Gmail não sejam apresentadas como envio concluído.
- Timeouts sejam tratados como resultados potencialmente incertos.
- O sistema não repita automaticamente envios de e-mail.
- Os resultados parciais sejam documentados.
- O workflow original continue intacto.
